# 封面海报的 ChatGPT 提示词

给 GitHub 项目做社交预览图 / README 横幅时用。直接整段复制粘贴。

---

## 主版本

```
帮我做一张 GitHub 项目的社交预览图（social preview），尺寸严格 1280×640 像素。

【项目背景】
名称：Jev Wingman
定位：基于 Jev 的 QQ 聊天决策辅助
它做什么：读取手机 QQ 当前聊天窗口的文字，交给决策模型给出五项类型化判定——
对方是否在等回复、对方意图、情绪强度、说错话风险、推荐回复策略。它只给判决，
不生成回复文本，也从不代发消息。判定可以跑在手机本地的离线模型上，也可以接
云端 Jev 兼容 API，两种模式随时切换，没有 key 时自动回退本地。

【画面构图】
- 左侧约 55% 是文案区，右侧 45% 放一部手机的正视图
- 手机屏幕里是聊天界面，界面右下角有一枚青绿色的玻璃悬浮球，球的左侧贴着
  一张半透明的毛玻璃判定卡片（一行行列出判定结果，卡片能隐约透出背后的
  聊天气泡），这就是产品的核心交互
- 整体气质参考 iOS 的 Liquid Glass 设计语言：半透明毛玻璃、大圆角、顶部受光、
  细腻的白色折射亮边、柔和的投影。克制、高级、留白充足

【配色】
- 背景主色：#0A2A26 深青，可以有一层极淡的青绿光晕，不要复杂纹理
- 强调色：#2BC4A0 青绿
- 文字：近白色，次级文字用低饱和的青灰

【文案 · 必须逐字照排，不要改写、不要出现错别字】
主标题：Jev Wingman
副标题：基于 Jev 的 QQ 聊天决策辅助
正文一行：读聊天窗口，给出类型化判定，不替你打字
三个标签胶囊：本地离线 / 云端 API   |   单次判定 49ms   |   不代发消息

【不要出现】
真实人名、真人头像、真实聊天内容、任何品牌 logo、赛博朋克式的霓虹堆砌、
花哨的渐变色块
```

## 如果中文字排不好，改用这一版

AI 生图对中文字形把握很差，经常出现糊字或错别字。碰到这种情况就别让它排字了，
改成只出视觉效果，文字后期自己叠——用 Figma、PS，甚至 PPT 都行。

```
帮我做一张 1280×640 的深色科技风背景图，用作软件项目封面。

【画面】
- 深青色背景（#0A2A26），带一层极淡的青绿光晕
- 右侧 45% 放一部手机的正视图，屏幕里是聊天界面，界面上有一枚青绿色玻璃悬浮球
  和一张半透明毛玻璃卡片（卡片透出背后的聊天气泡），体现"毛玻璃 + 玻璃球"的质感
- 参考 iOS Liquid Glass：半透明、大圆角、顶部受光、白色折射亮边、柔和投影
- 左侧 55% 完全留空、干净、无任何元素

【重要】
图上不要出现任何文字、字母、数字、logo 或水印。文字我会自己后期添加，
所以左侧必须是一块干净的空白区域。

【配色】
背景 #0A2A26，强调色 #2BC4A0，光影柔和克制，不要赛博朋克式霓虹。
```

## 浅色版（与 App 实际界面一致）

- 手机右下方可以有一点很淡的青绿光晕，但整体必须保持浅色

【文案 · 必须逐字照排，不要改写、不要错别字】
主标题：Jev Wingman
副标题：基于 Jev 的 QQ 聊天决策辅助

## 拿到图之后

1. 成品尺寸若不是 1280×640，先裁到这个比例——GitHub 的 social preview 就是这个规格。
2. 文字版本自己叠的话，主标题建议用粗体无衬线（思源黑体 / 苹方 / 微软雅黑 Bold），
   字号约 48px；副标题 22px 用强调色；标签做成圆角胶囊，描边 1px 半透明白。
3. 上传位置：仓库 → Settings → Social preview → Upload an image。
   这个字段 GitHub API 没有开放，只能在网页上手动传。
