# Jev 僚机封面图提示词

用于生成 GitHub 社交预览图，尺寸 1280×640。

## 视觉方向

- 浅冷灰背景，参考 Android 浅色系统界面。
- 左侧放 Jev 僚机标题和一句说明，右侧放手机正视图。
- 手机屏幕展示运行控制台：深蓝 J 双翼图标、权限状态卡、远端/本地模式切换和最近判定卡。
- 主色使用深海军蓝，强调色使用青绿色；卡片为白色大圆角，边框轻、阴影柔和。
- 画面克制、留白充足，不使用霓虹、复杂纹理或具体聊天品牌 Logo。

## 必须出现的文字

Jev 僚机
先看状态，再决定要不要出手
读取聊天窗口，给出类型化判定，不替你打字
远端 Jev · 本地模型 · 不代发消息

## 不要出现

真实人名、真人头像、真实聊天内容、账号信息、API Key、二维码、品牌 Logo、水印和错误文字。

如果生成器无法正确排中文字，请只生成无文字的浅色 UI 背景，文字在后期排版。
