# Jev 僚机 v1.9.1

## 这版更新

- 重构首页为运行控制台，先显示状态、权限、悬浮球和最近判定。
- 更新 J 双翼应用图标、深蓝和青绿色视觉系统。
- 增加远端 Jev / 本地模型分段切换。
- 增加高级设置、开发诊断和统一演示入口。
- 最近判定会校验当前抓取文本，避免旧结论错配。
- 无障碍服务未连接时不再显示“可使用”。
- 修复权限变化后无法停止悬浮球的问题。
- 修复页面旋转时异步判定停留在“正在判定”的问题。

## 安装

下载 jev-assist-v1.9.1.apk，在 Android 8.0 及以上设备安装。首次打开需要手动开启：

1. 显示在其他应用上层
2. Jev 僚机读取聊天内容

应用不会自动发送消息。
